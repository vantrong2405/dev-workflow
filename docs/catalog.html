Bắt đầu & thiết lập 4 lệnh

Chạy 1 lần cho project mới, hoặc dùng lệnh gộp để khỏi gọi tay từng bước.

CLAUDE.md của dự án bạn

Claude Code tự đọc file này mỗi lần mở dự án — ak tự ghi vào đó, ko phải bạn tự tay soạn.

Cách nó vào file này

  1. Lần đầu chạy /ak:learning ở 1 project → nếu repo chưa có CLAUDE.md, tạo mới; nếu đã có, chỉ chèn thêm khối đánh dấu bên dưới vào cuối file — chữ bạn viết sẵn ko bị đụng.
  2. Trong khối đó có tên project, đường dẫn workspace, cách gõ lệnh bắt đầu ticket, và convention chung ko phụ thuộc stack (chat tiếng gì, code luôn tiếng Anh, diff tối thiểu, comment chỉ giải thích tại sao, git ko tự commit/push, tuyệt đối ko force-push tự ý/ko push protected branch).
  3. Sau này slug/workspace/ngôn ngữ đổi → /ak:coaching tự cập nhật lại đúng khối đó, ko chạm phần khác.
  4. Bên trong có cả sơ đồ luồng + bảng lệnh tiện ích, ko chỉ vài dòng — xem đủ ở templates/CLAUDE.md trong repo ak (rút gọn dưới đây để dễ xem).
